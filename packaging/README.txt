# 服装裁片自动缝合标注工具 — 使用说明

一个**双击即用**的 Windows 桌面工具，整合了：

1. **DXF 自动标注**（auto-annotator）：上传 DXF，自动生成 `garment / seam` 两个 JSON。
2. **裁片预览与人工编辑**（seam-preview）：加载 JSON，进行可视化预览、人工缝合、语义编辑，并保存为 `.reviewed.json`。

已内置 Python 运行时与全部依赖，**无需额外安装任何软件**。

---

## 一、快速开始

1. 双击 **`启动工具.exe`**。
2. 稍候，程序会自动打开默认浏览器（地址形如 `http://127.0.0.1:8010/`）。
3. 在弹出的黑色控制台窗口中可看到本机端口；**关闭该控制台窗口即退出工具**。

> 如果浏览器没有自动弹出，请手动在地址栏输入控制台显示的 URL。

---

## 二、常用页面

| 页面 | 地址 | 用途 |
| :--- | :--- | :--- |
| 编辑器 | `http://127.0.0.1:8010/seam-preview/` | 加载 JSON，人工复核 / 缝合 / 语义编辑 |
| DXF 转换 | `http://127.0.0.1:8010/dxf-convert/` | 上传 DXF → 下载 garment / seam JSON |

### 推荐流程
1. 打开 **DXF 转换** 页，拖入 / 选择 `.dxf` 文件。
2. 标注完成后点击 **下载 garment.json** 与 **下载 seam.json**（文件名形如 `{名称}.garment.reviewed.json` / `{名称}.seam.reviewed.json`）。
3. 打开 **编辑器** 页，将这两个 JSON 一并拖入（或通过页面上的文件按钮选择）。
4. 执行人工缝合 / 语义编辑，最后保存为 `.reviewed.json`。

---

## 三、端口与多开

- 默认使用 `8010` 端口；若被占用会自动改用空闲端口，无需手动配置。
- 支持启动多个实例（各自占用不同端口）。

---

## 四、关闭方式

- 直接**关闭黑色的控制台窗口**，服务即可停止。
- 关闭浏览器窗口不会停止后台服务，请以控制台窗口为准。

---

## 五、常见问题

| 问题 | 说明 / 处理 |
| :--- | :--- |
| 无法打开页面 | 确认控制台窗口仍打开；复制其中 URL 到浏览器访问。 |
| 杀毒软件误报 | 打包程序未签名，部分杀软可能提示；选择“允许运行/信任”即可。 |
| 提示缺少 DLL | 运行对应系统的 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)；本工具为 64 位 + Win10/11。 |
| 想重新打包 | 使用 `auto-seam\packaging\build.bat`（需已建好 `auto-annotator\.venv`）。 |

---

## 六、目录结构

```
服装裁片自动缝合标注工具\
├─ 启动工具.exe        ← 双击运行入口
├─ 使用说明.txt         ← 本说明
└─ _internal\          ← 内置运行时与静态资源（请勿删除/移动）
   ├─ seam-preview\index.html
   └─ annotator-static\index.html
```

> 请将整个文件夹放到固定路径后使用；不要单独移动其中的某个文件，以免程序找不到资源。
